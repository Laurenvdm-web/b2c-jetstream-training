🎓 Guest Response Quick Reference

New hire starter guide · Message arrives → find the category below → apply the response for that stay status

Welcome! Start here. This is a simplified version of Lauren's full guest-response logic, built to cover the situations you'll run into most. Every category from the master file is here, just trimmed down to the core rule. Once you're comfortable with this, Lauren also has a fuller reference with response templates, trickier edge cases, and V2-property exceptions — ask her when you're ready for it.
⚠️ Golden rule: Never send a guest reply yourself without it being reviewed first. Always draft the response and have Lauren (or whoever is checking your work) confirm before it goes out. Sign every message "Lauren – Leavetown" unless you're told otherwise.
📋 How to use this page
1Check the guest's stay status tag: Inquiry (hasn't booked yet), Pre-stay (booked, hasn't arrived), or In-house (currently staying).
2Read the guest's message and find the closest matching category below — click it to expand.
3Use the response for that stay status. If a Cirrus badge appears, look that detail up in Cirrus rather than guessing.
4Can't find a match, or something feels off? Don't guess — flag it to Lauren with your best-guess draft attached.

1. Availability Request
Question
▼
Can we have an early check-in?Is a late check-out possible?Can we request a specific bed configuration?
Inquiry
Once booking is confirmed, guest gets the front desk number to ask directly. Based on availability, never guaranteed.
Pre-stay
Cirrus Pull front desk #. Direct to front desk. Based on availability.
In-house
Cirrus Pull front desk #. Direct to front desk — treat as priority if urgent.
Watch for: if the guest asks us to pass the request to the property ourselves (instead of calling directly), do that — message the partner with the request — but still tell the guest it can't be guaranteed.
💬 Worked examples
Guest asks (Inquiry): "Is a late check-out possible?"
Reply: Hello,
Thank you for your message.
Once your booking is confirmed, you will receive the front desk number and will be able to contact them directly regarding a late check-out. Please note this is based on availability and cannot be guaranteed.
If you have any further questions I will be happy to assist.
Kind regards,
Lauren – Leavetown

4. Check-in / Access
Question
▼
Is it self check-in?Where do we collect the keys?Do we access via code or will someone give us keys?
Inquiry
Instructions sent once confirmed. If asked "is it self check-in?" — no, you'll check in at the front desk.

Cirrus VRBO: give address + check-in time, resend instructions, mention spam folder. Airbnb/Booking.com: give address + time, no spam note.

22. Front Desk Unreachable / Discrepancy
Question Statement
▼
We called reception and haven't heard back.The number you gave doesn't work.The property told us something different than our booking says.
Cirrus Always check the number in Cirrus first, don't assume the guest dialed wrong or that Cirrus is outdated.

Waiting on a callback: if the number matches Cirrus, tell them to try again, it's correct.
Number seems wrong: if Cirrus shows a different number, apologize and give the correct one. If it's the same, tell them it's correct and suggest trying again.
Already tried and failed / given a wrong number by someone: don't send them back to redial. Tell them we'll contact the property ourselves, then actually do it.
Property told them something different than our records: don't contradict the property. Flag to Lauren before responding.
💬 Worked example
Guest asks (Pre-stay): "We called the reception but haven't heard back."
Reply: Hello Yves,
Thank you for your message.
The number you called, (555) 123-4567, is the correct number for the on-site team. Please try calling them again directly and they will be able to assist you.
If you have any further questions I will be happy to assist.
Kind regards,
Lauren – Leavetown

16. Distance to Nearby Venue / Attraction
Question
▼
How far are you from the airport?What's the distance to downtown?
Cirrus Check the property description and Local Favorites first. If nothing exact, web search the distance. Never invent a number, if you can't find a reliable answer, say it isn't on file and suggest a maps app.
Watch for: at Inquiry stage, never name the property, the exact building, or a specific landmark, even if you found it. Keep it generic ("a few minutes' walk"). A named landmark can be reverse-searched to find the exact address before the guest has even booked. Once confirmed, be as specific as Cirrus/search supports.
💬 Worked example
Guest asks (Inquiry): "How far are you from the ski lifts?"
Reply: Hello,
Thank you for your message.
The property is just a short walk from the slopes, no car needed.
If you have any further questions I will be happy to assist.
Kind regards,
Lauren – Leavetown

21. PMR / Accessibility Request
Question
▼
Is the apartment wheelchair accessible?Is there step-free access?
Cirrus Check every unit at the resort, not just the one the guest asked about. Only rely on an explicit accessibility note in Cirrus, never guess from general listing info (like "ground floor").

If nothing is found anywhere: tell the guest directly the property isn't suitable for reduced mobility, no accessibility note = treated as not accessible. If one unit is confirmed accessible: point them to it.
💬 Worked examples
Guest asks (Inquiry): "Is there step-free access to the unit?"
Reply: Hello,
Thank you for your message.
After checking, unfortunately this property is not adapted or suitable for a guest with reduced mobility.
If you have any further questions I will be happy to assist.
Kind regards,
Lauren – Leavetown

28. Guest Reports On-Site Issue (Mid-Stay, First Time)
Statement
▼
We woke up to ants swarming the kitchen counter.There's a leak under the bathroom sink.
In-house, first time this issue is reported (if it's near check-out instead, use Category 19). No Cirrus needed.

1. Apologize and acknowledge.
2. If they haven't said they already told the front desk, ask if they have (skip if they already said yes).
3. If it's something photographable, ask for a couple of photos.
4. Tell them it'll be escalated to the management team once that info is in.

No "further questions" line.
💬 Worked example
Guest says (In-house, mid-stay): "We woke up to ants swarming the kitchen counter."
Reply: Hello,
I'm so sorry to hear this, thank you for letting us know.
Have you already reported this to the front desk?
If you're able to, could you please send a couple of photos?
Once we have that information we will escalate this to our management team.
Kind regards,
Lauren – Leavetown
